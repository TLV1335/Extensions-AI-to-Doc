Cấu hình AI to Google Docs

1. Kết nối Google Apps Script
Đường dẫn Web App kết thúc bằng /exec (ví dụ: https://script.google.com/macros/s/.../exec)
Mã token bí mật trùng khớp với Script Property TOKEN trong Apps Script
2. Danh sách Google Docs & Doc Mặc định
Chọn từ menu sổ xuống. Tất cả các trang AI sẽ tự động lưu vào Doc này (trừ khi trang đó được gán Doc riêng).
Dán link Google Doc (hoặc ID) rồi bấm nút để hệ thống tự động tìm và lấy tên tài liệu:

3. Tùy chọn nâng cao: Chỉ định Doc riêng theo từng trang
Nếu chọn "(Dùng Google Doc mặc định chung)", trang đó sẽ tự động lưu theo menu số 2 ở trên.
