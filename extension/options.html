🚀 Cài đặt AI to Google Docs

1. Phương thức kết nối

Tự động kết nối trực tiếp với Google Docs qua tài khoản của bạn. Không cần tạo Apps Script hay cấu hình mã nguồn phức tạp.

Cấu hình OAuth Client ID riêng (Dành cho Developer)
Nếu bạn tự tạo OAuth Client ID trên Google Cloud Console, hãy dán Client ID vào đây:
Đường dẫn Redirect URI của extension này:
✓ Đã kết nối: email@example.com
Đường dẫn Web App kết thúc bằng /exec (ví dụ: https://script.google.com/macros/s/.../exec)
Mã token bí mật trùng khớp với Script Property TOKEN trong Apps Script
