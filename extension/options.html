Cấu hình AI to Google Docs

1. Kết nối Google Apps Script
Đường dẫn Web App kết thúc bằng /exec (ví dụ: https://script.google.com/macros/s/.../exec)
Mã token bí mật trùng khớp với Script Property TOKEN trong Apps Script
2. Google Doc Mặc định (Áp dụng chung)
Mọi trang AI sẽ tự động lưu vào Google Doc này (nếu không cài Doc riêng bên dưới). Bạn có thể copy nguyên link trang Google Doc dán vào đây.
3. Tùy chọn nâng cao: Chỉ định Doc riêng theo từng trang
Nếu để trống, trang đó sẽ tự động lưu vào Google Doc mặc định ở trên.
NotebookLM (notebooklm.google.com)
ChatGPT (chatgpt.com)
DeepSeek (chat.deepseek.com)
Gemini (gemini.google.com)
Claude (claude.ai)
